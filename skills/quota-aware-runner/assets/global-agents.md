## Sol–Luna project workflow

For every task that creates, modifies, fixes, refactors, reviews, tests, or configures software or project artifacts, including project documentation, you must load and follow `$sol-luna-handoff`. Let the Skill select the route using its adaptive Tier 1, Tier 2, and Tier 3 predicates, and advance automatically within that route without pausing for routine confirmation.

This rule excludes general Q&A, translation, and prose-only work that does not modify a project artifact.
